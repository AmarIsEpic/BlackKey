# BlackKey 🔐

BlackKey is a web-based password strength checker built with HTML, CSS, and JavaScript. The application evaluates how strong a password is and estimates how long it would take to crack it, helping users better understand password security.

The project uses a simple, framework-free setup with all files located in the main branch: `index.html` for structure, `style.css` for styling, and `script.js` for the password analysis logic. The interface is clean, responsive, and works smoothly on both desktop and mobile devices.

The project is deployed using GitHub Pages. Since all files are in the main branch root, no build steps or configuration are required. To deploy, push the repository to GitHub, go to **Settings → Pages**, select the `main` branch and the `/root` folder, then save. The live version will be available at `https://amarisepic.github.io/BlackKey/`.
